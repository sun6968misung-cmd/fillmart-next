## 3. 페이지 간 연결 흐름

### 3-1. 카카오 채널 진입 시나리오 (주요 진입점)
```
카카오 채널 링크 [확인 필요]
  └→ / (홈)
       ├→ 이번 주 행사 섹션 → 상품 카드 클릭 → /product/[id]
       │                                         └→ 장바구니 담기 → /cart → /checkout → /success
       ├→ 타임딜 배너 → /flash-product/[idx]
       ├→ 카테고리 탐색 → /?cat=야채/채소 → /product/[id]
       └→ 매장 위치·전화 (홈 하단) → 전화 앱 / 지도 앱 이탈
```

### 3-2. 구매 완료 흐름
```
/cart → /checkout → (Toss 결제) → /success
                  → (결제 실패)  → /fail → /cart (재시도)
                  → (만나서 결제) → /success (직접 리다이렉트)
```

### 3-3. 비로그인 → 로그인 강제
```
상품 담기 시도 → /auth (로그인) → /cart (복귀)
찜하기 시도   → /auth (로그인) → 원래 페이지 복귀
```

### 3-4. 관리자 진입
```
/ → 관리자 버튼(숨김) → 비밀번호 입력 → /admin (overlay)
/product/[id] → "관리자 편집" 버튼 (admin_active 상태일 때만 표시)
```
