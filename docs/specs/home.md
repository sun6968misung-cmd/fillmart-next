# 홈페이지(`/`) 스펙 v0.1
> 작성일: 2026-09-08 | 상태: 초안 (brief.md 미입력 항목 다수)

---

## 목적
카카오 채널·지인 공유로 처음 방문한 손님이 **30초 안에 매장 위치·전화·이번 주 행사를 파악하고, 원하는 상품을 담아 결제까지 이어가도록** 하는 진입 페이지.

---

## 핵심 사용자 시나리오

| # | 시나리오 | 성공 기준 |
|---|----------|-----------|
| 1 | 단골 손님이 카카오 채널 링크를 타고 와 "이번 주 삼겹살 행사 있어?" 확인 | 홈 스크롤 한 번으로 행사 상품·가격 확인 |
| 2 | 업소 사장님이 대용량 식자재 가격 비교 후 바로 전화 주문 | 홈 하단에서 전화번호 탭 한 번으로 전화 연결 |
| 3 | 처음 방문한 손님이 "여기가 어딘지" 확인 후 매장 방문 결정 | 홈 하단 지도 링크·영업시간으로 즉시 확인 |

## 화면 구성 (위 → 아래)

### S1. 헤더 (고정, sticky)
- 필마트 로고 (좌) — 에셋 [확인 필요]
- 카카오 채널 바로가기 버튼 또는 아이콘 (우) — 링크 [확인 필요]
- 찜 아이콘 · 장바구니 아이콘 (우)
- 로그인 상태: 이름 표시 / 비로그인: "로그인" 텍스트

### S2. 히어로 배너 (HeroBanner)
- 이미지 슬라이드 또는 단일 풀위드 배너
- 내용: 이번 주 메인 프로모션 or 매장 소개 슬로건
- CTA 버튼: "행사 상품 보기" → 페이지 내 S4 섹션으로 스크롤 or `/category/[slug]`
- 에셋: 배너 이미지 [확인 필요] — 주 1회 갱신 주체 [확인 필요]

### S3. 매장 핵심 정보 바 (모바일 최우선)
- 상모점 전화번호 — `tel:` 링크 [확인 필요]
- 다사점 전화번호 — `tel:` 링크 [확인 필요]
- 오늘 영업 여부 + 영업시간 (동적: 요일 자동 판단) [확인 필요]
- 위치 보기 버튼 → 카카오맵/네이버지도 링크 [확인 필요]

> 이 섹션은 **픽스드 정보 바** 형태로 히어로 바로 아래 배치.
> 동네 손님에게 전화·위치가 1순위임을 반영.

### S4. 타임딜 / 이번 주 행사 (FlashSaleSection)
- 타이머: 행사 종료까지 남은 시간 (startHour–endHour 범위일 때만 표시)
- 상품 카드 가로 스크롤 (모바일) / 그리드 (데스크톱)
- 카드: 상품 이미지, 이름, 원가(취소선), 행사가, 1인 구매 한도 배지
- 행사 외 시간대: 섹션 숨김 (현재 구현과 동일)
- 데이터 출처: `pilmart_flash_sale` (관리자 설정)

### S5. 카테고리 퀵 링크
- 아이콘 + 라벨 형태, 가로 스크롤 (모바일)
- 우선 노출 카테고리: 야채/채소, 과일, 축산/계란, 수산/건어물, 쌀/잡곡, 대용량 (업소용)
- 탭/버튼 클릭 → `/?cat=[카테고리]` (사이드바 필터 열림)

### S6. 상품 그리드 (ProductGrid)
- 기본: 전체 상품 (~60개) 4열(데스크톱) / 2열(모바일) 그리드
- `?cat=` 파라미터 시: 카테고리 필터 사이드바 + 해당 카테고리 상품만 표시
- 카드: 이미지, 이름, 가격, 담기 버튼
- 정렬: [확인 필요] — 기본 정렬 기준 (인기순? 등록순?)

### S7. 공지사항 미리보기
- 최신 공지 2–3건 리스트
- "더 보기" → `/notice`
- 데이터 출처: `pilmart_notices` (관리자 설정)

### S8. 푸터
- 법인명: 주식회사 필식자재마트
- 대표자명: [확인 필요]
- 사업자등록번호: [확인 필요]
- 상모점: 주소 [확인 필요] · 전화 [확인 필요]
- 다사점: 주소 [확인 필요] · 전화 [확인 필요]
- 영업시간: [확인 필요]
- 이메일: [확인 필요]
- 카카오 채널 링크: [확인 필요]
- SNS 링크 (인스타 등): [확인 필요]
- 필통치킨 링크: [확인 필요] (노출 여부 대표 결정 필요)
- 이용약관 · 개인정보처리방침 링크
